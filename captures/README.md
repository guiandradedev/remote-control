# captures

Dados brutos dos experimentos de captura do controle IR.

- `SCENARIOS.md` — lista dos cenários a capturar e o status de cada um.
- `samsung-ac/` — uma linha `const uint16_t ...` por arquivo (`.txt`), copiada do Serial do `Q0962-Experimento`.

Não edite os vetores à mão. Se precisar de uma nova captura, grave de novo com o Experimento e substitua o arquivo.
